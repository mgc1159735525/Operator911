v0.13新增「今夜指引」：下一步目标、成本与收益、空闲成员推荐、临期主线提醒和无效接收拦截。交通站支持追查、地址知识隔离、搜查损失与转移恢复。详见 `Docs/Minglu/行动引导与组织安全_v13.md`。

v0.11支持写实五官独立混搭，男女独立发型、男性胡须及发须染色，并接入随机角色、预设和存档。详见 `Docs/Minglu/独立五官与发须_v11.md`。

v0.10新增写实男女分层立绘，新招募候选人按种子生成并保持外观，支持男女切换、服装和配色。详见 `Docs/Minglu/写实外观_v10.md`。

v0.9新增组合外观：负责人及队员可编辑13类部件与配色，实时预览，3个跨局预设，支持恢复原立绘。详见 `Docs/Minglu/组合外观_v09.md`。本次兼容原有v8对局存档。

v0.8新增地区负责人情报交通：派人接收、跨夜外送、回执收益、三条潜伏联络和存档恢复。新战役自动进入情报交通。详见 `Docs/Minglu/地区情报交通_v08.md`。

v0.7新增12处可巡访地点、三种地图显示层、永久线索、6宗双方案案件和4条后续任务；共34项任务条目。热度与支持实际影响暴露，同案方案互斥。详见 `Docs/Minglu/城市案件与地图_v07.md`。Unity菜单 `Minglu > 城市地点与案件配置` 提供校验和导入导出。

新版本默认提供「新京二十夜」战役：四阶段、18任务、9事件、主线最终起义、四能力与成长、延迟后果及多结局。可在新局页切回八夜试玩。详细内容与限制见 `Docs/Minglu/新京二十夜战役_v06.md`。`Minglu > 战役内容配置` 可校验、编辑、导入、导出战役JSON。

启动进入主菜单。选择开始新局，配置难度、开局方案、种子与危机开局，再出发。支持继续、设置、暂停保存返回、结算战绩与重开。每局状态独立，局外保留设置与战绩。

新局进入「组织事务」可接引三位候选人、管理精神与身份维持、派成员长期潜伏并递送产出的情报。候选人属性由种子生成，复用现有肖像。八夜试玩潜伏周期三夜，20夜战役周期五夜；身份维持目前花银两，不收原案的分数AP。

新增规则入口：Unity `Minglu > 组织规则配置`，支持校验与JSON导入导出。原有Excel导表继续使用；新组织规则暂不在Excel中。

Unity中使用 `Minglu > 打开八回合原型` 后Play。现有 `Main.unity` 和HeroDispatch资源继续保留。

配置工作簿位于 `outputs/minglu-v03/明路地下_游戏配置.xlsx`。
使用 `Minglu > 配置表工具` 预览校验并导入，修改后新开局生效。
