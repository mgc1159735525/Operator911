## 当前可玩框架

- **二十夜剧情战役**：新局根据种子选择“未寄出的名单”“冬粮账簿”“断线之前”中的一个剧本。每局三章、每章两种处理方法；配置总计 3 个剧本、9 章、18 种方法，单局不等于体验全部 18 种方法。
- **双重目标**：完成三章委任，并达到当局组织的送达、成果与身份门槛。地图显示当前主线；“主线委任 → 行动进度 / 组织概况”查看还缺什么。八夜短局与此前已开始的对局保留原有通关规则，读档不会强加新剧情。
- **随机组织成员**：随机姓名、男女外观、能力、职业、性格和生活背景。地下能力决定骰数，表身份决定部分任务准入；安排出勤、休养和任职时需要取舍。
- **机构情报**：只有在敌方政务、税务、巡防或驻军机构任职的内线会产出机构报告。民间成员可承担联络和交通，普通任务与日常生活不直接奖励库存情报。
- **自动传递链**：内线 → 接头人 → 交通员，三个岗位逐夜工作。任务优先占用人手，岗位冲突、休养、失陷与情报老化均影响送达。每环判定与预计工作可查看。
- **机构档案**：新剧情在报告产出时记录来源，按待接、中继、送达顺序流转；先进入队列的报告先传递。正常换岗保留原报告的机构与来源，换人不会把旧报告改成新机构报告。已送达的报告永久归档，可解锁本章核证方法，核证不重复扣除库存情报。
- **今夜安排**：集中查看已签发任务、正常联络链、待续办阶段、人员与链条冲突。点开任务、联络网或成员处理后返回核对，最终确认才推进一夜。失败、调查与阶段进度均有可回看的结果要报。
- **任务授权**：比较人选，选择直接执行或先调查，以及常规、筹备、紧急方案。可选情报支援；提交前查看成功率、成本、连勤与岗位冲突。多阶段任务每夜重新授权，阶段成功会保留。
- **章节方法取舍**：对应机构档案支持一阶段核证；不依赖指定档案的方法通常需要两阶段。尚未执行的方法可以重选，已授权时先撤回负责人；一旦已有执行结果、调查成果或阶段进度，就保留当前方法继续推进。
- **组织生活与危机**：本职成长、能力经验、地方盟友、民心、追查、临时离岗、信任事件、被捕与营救。成员的日常安排自动执行。
- **反馈与复盘**：夜间要报合并呈现，值夜报告保留完整判定。“值夜报告 → 要报留档”可回看最近 80 则要报并跳转相关档案。剧情结局记录章节方法与组织结果。
- **人物绘卷**：男女分层立绘、脸型与五官循环切换、发型、男性胡须、服装和配色、锁定随机、撤销重做与跨局预设。长者默认优先银白须发，外观不影响能力。

地图始终是指挥桌面。任务簿、联络网、人事档案、值夜报告、地方事务与主线委任通过按钮打开弹窗；保存、读取、指南和退出集中于设置。

## 第一次游玩

没有已完成战绩时，新局默认“初探”，仍可自由选择难度。建议先用二十夜体验完整循环：第一夜跟随底部建议签发一项任务并看结果，第二夜建立机构联络链，再打开主线委任选择本章方法。浏览界面不推进时间，只有确认“结束今夜”才执行。

八夜是短局挑战，时间更紧，不等于新手教学。普通机会不必全部接受，空闲成员会处理生活与成长。

## 保存与恢复

存档继续使用既有目录，即使游戏显示名称改变也不迁移用户数据：

`%USERPROFILE%\AppData\LocalLow\DefaultCompany\Operator911`

当前首脑对局为 `minglu-run-v14.json`，设置、人物预设与战绩为 `minglu-profile-v1.json`；名称保留是兼容约定。保存采用校验后的临时文件替换，上一份有效主档保留为 `.bak`。

读取时先校验主档；主档损坏或缺失时，尝试有效 `.bak` 并显示恢复提示，进度可能略早。读取本身不修改原文件；恢复后保存会保留损坏原件为 `.corrupt-*`。主档和备份都不可用时保留文件并显示错误，不将失败读取当作成功。开始新局前，即使只剩备份，也会要求确认替换。

## 距离商业发行还缺什么

1. 至少 5 名首次接触游戏的玩家完成上手测试，观察能否在 15 分钟内独立签发、建立链条并说明下一目标。
2. 二十夜中段重复感、失败后的恢复空间、策略差异与真实游玩时长测试；单局 2–3 小时是设计目标，尚非测得结果。
3. 内容深化：目前仅 3 种性格、6 种生活背景；机构差异主要体现于报告类型和任务；章节带来的长期组织资产尚未实现。
4. 音频目前只有界面点击反馈，没有背景音乐；还需整体声音与情绪节奏设计。
5. 完整字体、美术和音频商业来源清单及发行所需 AI 内容说明尚未核实完成。
6. 目标 PC 硬件、宽屏与系统缩放的兼容性、性能和可读性验收。
7. Steam 后台 AppID、商店文案与图像、预告片、内容问卷、构建上传及审核均未完成。
