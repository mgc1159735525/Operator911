## 四项不能混淆的实现

1. **情报点不是情报网络。** 当前情报是一个可花费的整数，没有分类、持有人、传递路径、据点存储、截获与有效期。
2. **联系卡片不是恩怨图谱。** 当前只有上线ID和其文字展示，不存在信任、仇恨、爱慕等关系数据与行为。
3. **战绩不是跨局成长。** 当前没有影响力获取/消费、传承节点、遗产角色或解锁奖励。
4. **种子随机风险不是完整肉鸽内容生成。** 地图布局、四个人物、七项任务和三条剧情密报仍为固定内容；随机的是区域风险与行动骰。

## 有意简化或方向待统一

- 原案以“黑箱人性”为核心，隐藏或模糊能力、性格及成功预期；现版为调试与操作清晰度直接展示能力、暴露和精确成功率。正式信息披露规则需要重新确定。
- 原案10明确采用带影响力、传承树的Roguelite双线养成；用户最近要求参考传统肉鸽，因此v0.4先做每局归零和战绩留存。原案跨局成长确实未做，但不能未经取舍就默认加回永久数值升级。
- 原案13是20回合四阶段，现版是8夜验证切片。将turns改为20不会自动产生阶段任务、事件和敌方行为。
- 原案早期人物采用1760年代架空背景，后续17/19出现记者、地下电台等近现代元素；AP也出现整数与0.5、1.5单位等不同口径。当前采用古代视觉、整数AP和四名固定角色。扩大内容前需要统一设定和规则。
- 原案19的一般规则规定下线不知道上线真名，但个别叛变示例出现供出上线真名。需要以“角色实际掌握信息”为准澄清例外，而不能直接照表实现矛盾规则。

## 建议制作顺序

1. **人物与人事基础**：补齐四维能力、精神和完整状态；招募与容量；基础身份功能。让人员损耗能被补充，人物区别影响选择。
2. **谍报主干**：身份维持/可疑度、据点、情报分类与传递、长期潜伏、断线重组。形成不同于普通任务调度游戏的核心体验。
3. **人物行为与敌方**：隐藏性格、动机、少量恩怨、敌方人物/AI、策反与双面间谍。
4. **组织运营**：资金、物资、六设施、成长与多人协作；联动任务奖励和维护成本。
5. **完整战役**：延迟因果与永久标记、20回合阶段池、多结局、随机内容、平衡测试。
6. **内容与表现收尾**：完整角色创建/捏脸、部件资产、事件插画、动画、音频、交互适配；再根据最终肉鸽方向决定跨局成长范围。

本次为对照审计，没有修改游戏规则或新增这些未完成功能。
