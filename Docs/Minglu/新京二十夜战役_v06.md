# 新京二十夜 · v0.6

本轮根据原案压缩包的回合节奏、任务、角色、成长和剧情因果系统，制作了第一章可玩的20夜战役。它是正式内容制作的首个里程碑，仍不是原案所有系统完成的商业发行版。

## 开始游戏

运行 `Builds/MingluCity/MingluCity.exe`，开始新局默认选择「新京战役 · 20夜」。可切换回八夜快速试玩。难度、种子、开局方案、危机开关继续有效。首次体验建议标准、均衡联络、关闭危机。

优先执行「古寺落脚」。主线依次是「古寺落脚 → 重接旧线 → 守军密约 → 最终起义」。后续任务在对应阶段解锁，前置必须成功完成；逾期意味着这条路线中断。失败的行动在截止前可以再次尝试。战役进度页显示主线状态和延迟搜查。

完成最终起义且成果达到目标才获胜，最早第17夜；仅攒够成果不会提前结束。初探/标准/险境目标分别66/70/78。第20夜仍可行动，结算后判断结局。

## 本轮制作内容

| 原案方向 | 本轮实际实现 |
|---|---|
| 13 回合节奏 | 蛰伏1—4、活跃5—10、高压11—16、决战17—20，阶段压力与进度页 |
| 05 任务 | 18项固定编排任务，主线及可选支线；接头、思想传播接入掷骰、推荐和派遣 |
| 02 角色 | 情报、潜行、说服、组织四项能力；身份专长加骰与小传 |
| 10 成长 | 成功行动累计4次，对应能力+1，上限5，存档保留经验 |
| 06 事件 | 9项按夜触发的二选一事件，资源门槛、阶段叙事与保护百姓标记 |
| 18 剧情因果 | 前置任务、即时资金/压力、两夜后报复、永久标记与结局判断 |
| 15/16 界面 | 新局战役模式、战役进度、主线状态、延迟后果、四能力人物档案 |

五种结局：成功且无人永久失联、保护过百姓为「明路」；其他成功为「解放」；失败且至少两人永久失联为「悲剧」；其他失败按成果是否达到30分为「妥协」或「长夜」。这是本轮规则，尚非原案完整多结局因果网络。

## 角色与行动

秘密接头使用说服，成功降低5点敌方压力；散布思想使用组织并增加4点成果。商人接头、教师传播、军官破坏、记者侦察分别加1骰。医生身份目前无专属治疗，人物说明和战役页明确标示；基础休整与营救仍可用。

沈默沿用联络员身份背景并补充城防任职经历，顾青为书坊伙计/教师，陈砚为行商，林叔为郎中。所有外观继续使用现有四幅肖像，并未新增捏脸或动态状态立绘。原案中的身份分类与旧时代城市美术存在混用，本章不引入现代通讯设备；「记者」保留为配置可选分类，初始阵容未使用。

战役每夜4AP；组织初始48银，每夜收入12，身份维持仍是每人2银，容量上限8，潜伏周期5夜。新章数值是适配20夜的首轮调试值，不声称已经达到发行平衡。

## 内容配置与导入

运行资源：`Assets/Minglu/Resources/Minglu/Config/campaign_xinjing.json`。

Unity菜单 `Minglu > 战役内容配置` 支持JSON编辑、导入预览、结构与依赖校验、导出、发布。发布前会验证四阶段覆盖、任务前置期限、动作、地图引用、奖励、角色能力及事件兜底选项；旧配置备份为`.bak`。运行配置变化仅影响新局，进行中的局使用快照。

| 数据组 | 内容 |
|---|---|
| stages | 阶段id、名称、起止夜、每夜压力、说明 |
| missions.task | 任务id、标题、正文、动作、区域、开放/截止夜、前置、优先级、奖励与逾期压力 |
| missions后果字段 | pressureDelta、money、retaliationDelay、retaliationPressure、flag |
| events | 夜、标题正文、两项选择、各自情报/成果/压力变化 |
| characters | 基础角色id、表身份、背景小传、说服和组织 |

基础角色/城市/动作/试玩任务仍使用既有 `outputs/minglu-v03/明路地下_游戏配置.xlsx` 与原有导表工具。**新战役内容此次以JSON为权威配置，未伪装成已纳入旧Excel。** 组织经济继续由组织规则工具维护，战役初始化覆盖上述长期战役参数。

v0.6独立存档为`minglu-run-v6.json`，不覆盖v0.5；局外设置与战绩继续共用`minglu-profile-v1.json`。存档包含战役全文、角色经验、永久标记和待结算后果。

## 验证入口

Unity菜单 `Minglu > 验证20夜战役`；批量验证及构建入口为 `Minglu.EditorTools.CampaignVerification.BatchDeliver`。测试覆盖阶段边界、胜负条件、标记选择、成长上限、前置锁定、延迟结算及200局逐夜存读档。自动策略的胜负分布仅用于排查逻辑，不代表真人胜率。
