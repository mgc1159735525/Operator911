# 城市案件与街巷地图 v0.7

本轮将新京从区域派遣底图扩展为可调查的城市：6个区域、12处具体地点、6宗双方案案件和4条后续任务。原有18项战役任务保留，新局共有34项任务条目；其中互斥方案不能在同一局全部完成。

## 参考与转化

[《这就是警察》官方介绍](https://store.steampowered.com/app/443810/This_Is_the_Police/)强调管理人员、应对事件、调查证据，以及与城市不同势力交涉。这里把这些设计方向转成限时案件、人选比较、现场处理方案和区域后果。

[《苏丹的游戏》官方介绍](https://store.steampowered.com/app/3117820/Sultans_Game/)强调周期性限期挑战、盟友和资源分配，以及选择对故事的后续影响。这里采用永久线索、条件解锁和不可兼得的处理路线，融入原有20夜战役。

以上是本作的设计转化，不声称复刻两款游戏的完整规则。没有复制它们的人物、剧情文本、美术或UI资源。

## 可玩循环

1. 在地图点击地点，查看背景、巡访行动及可取得的线索。
2. 选择成员，比较右侧成功率，点击「派遣巡访」或签发指令。巡访占1AP，沿用该地点行动的体力、暴露与成功检定。
3. 结算成功后首次记录地点，并取得永久线索；失败不解锁。线索不消耗，也不重复堆叠。
4. 线索解锁新地点与案件处理方案。选择方案后派人执行；行动失败可在截止前重试，成功则永久关闭同案其他方案。
5. 地区热度、民众支持、资金、成果与后续搜查按方案改变，影响下一夜。

线索属于情报信息，不是可拖拽、可消耗的实体卡牌。本轮没有加入物品装备槽或卡牌拖拽。

## 地图变化与数值

新增街道联系、河道方位、地点标记、区域档案、在地线报列表和线索簿。地图支持线报、搜查、民心三种显示层。背景继续使用现有城市美术，本次新增的是代码绘制的地图叠层与真实交互，未新增城市插画。

- 热度、支持均为0—100，每区独立。初始热度等于本局区域risk，支持10。
- 当前区域热度每25点增加3点行动暴露；支持≥40抵消2点，附加暴露最低0。
- 接头改变热度−6，破坏+12，其他外出行动+4；失败再+4。接头、传播成功增加4支持。
- 案件完成另结算配置中的heat/support变化。热度每夜自然−2。
- 结算按成员顺序执行，前序行动可能改变后续人员面对的区域热度；界面显示当前状态的风险。

道路用于城市方位与地点关系展示；本轮没有加入通行时间、道路封锁寻路或实时车辆模拟。地点也不等于可建造设施。支持40以上暂只有暴露修正，没有独立民兵或区域解放系统。

## 配置与存档

权威数据为 `Assets/Minglu/Resources/Minglu/Config/city_content.json`。Unity菜单 `Minglu > 城市地点与案件配置` 支持JSON编辑、导入预览、引用校验、导出与发布。原有战役/组织/Excel配置工具保留。新城市数据暂未加入旧Excel工作簿。

- sites：id、name、district、x/y、description、duty、evidence、requires。
- cases：mission（复用战役任务/后果字段）、site、group、requires、grants、outcome、heat、support。
- group相同表示同案互斥；requires/grants使用线索名称引用。
- 调整案例时仍需符合基础任务的前置截止夜早于后续开放夜的约束。

新局默认加载城市内容。v0.7使用独立`minglu-run-v7.json`，保留旧版本文件、不自动迁移旧局。新存档包含完整城市配置、线索、已访地点、各区热度/支持和已派巡访指令。八夜试玩保持原有地图与规则。

本次没有实现敌方人物AI、关系性格、捏脸、设施、物品系统或完整事件编排语言；这些仍属于后续原案系统。

## 验证

`Minglu > 验证城市地点与案件`检查地点解锁、成功/失败巡访、互斥派遣、替换与撤回、一次性后果、同案逾期去重、区域风险、组织改派和存档。另跑100局集成城市战役，保留全部既有回归验证。

批量验证和构建入口：`Minglu.EditorTools.CityContentVerification.BatchDeliver`。
