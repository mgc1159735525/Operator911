# 独立五官与发须 v0.11

写实模式现在支持独立选择眼睛、眉毛、鼻子、嘴巴、耳朵。每类四个部件，来自同性别四套年龄面容，在对应部位做柔化边缘与肤色校正，不再要求整张脸同步更换。当前双眼与双眉成对选择，左右耳成对选择，没有单侧编辑和尺寸拖拽。

男性四种发型：束髻、短束、披发、巾帽；女性四种发型：高髻、低髻、侧髻、半束。男性胡须：无、短须、长须、八字须。提供乌黑、栗棕、霜灰、银白四档发须颜色。女性不显示胡须层。

在外观编辑器选择写实模式，点击对应类别，再选部件；预览即刻更新。发型与胡须不会重置五官。主菜单负责人、当前队员、预设及存档都使用同一份组合数据。

## 兼容和随机生成

旧存档新增开关默认关闭，保持以前的完整面容。首次编辑五官时，将其他五官初始化为当前基础面容，再只替换所选部件。首次编辑发型/胡须/发色时启用无发底图与发须分层，保留现有五官选择。新随机角色同时生成五官、耳朵、发型、发色和男性胡须；女性随机角色的胡须值为0。

同种子同版本生成结果可复现；已存档的角色不重新随机。新版本随机字段增加，未来新局外观与旧版本同种子结果可能不同，任务随机流不受影响。原有经典模式仍保留。

## 实现和素材

- `PortraitFeatures.shader`：局部UV取样、柔化合成和皮肤色调匹配；同一材质支持发须灰度染色。
- `FeaturePortrait.cs`：为立绘设置部件参数并释放材质，支持UI裁剪。
- `RealisticPortraitUI.cs`：五官入口、独立发须图层和图集裁切坐标。
- `Appearance.featureEditing / groomingEditing / ears`：新增状态，其余部件沿用旧索引。
- `bald-atlas-v11.png`：保留身份、五官和服装的无发底图。
- `hair-atlas-v11.png`：独立男女发型与胡须。图集坐标按实际生成布局校准，避免采到相邻部件。图中额外尖须素材目前未进入选项。

两张新增图片均通过内置 image_gen 生成/编辑，原图保留，项目文件位于 `Assets/Minglu/Resources/Minglu/Art/`。没有使用其他游戏美术。提示词详见同目录 `独立发须_生成提示词.md`。

## 验证入口

编辑器：`Minglu.EditorTools.FeatureAppearanceVerification.BatchDeliver`。

运行参数：`--minglu-capture <PNG输出路径> --features-only`。测试不仅点击选项，还比较头像区域像素，确认五官选择确实改变渲染结果。
