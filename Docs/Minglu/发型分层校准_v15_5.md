# 发型分层校准 v15.5

本轮在游戏内增加头部近景验收图，不再仅以缩小后的整身图判断拼接效果。

## 已修改
- 原逻辑在头后完整画一遍头发，再在脸前画一遍上半部。半透明发丝会重复叠加。现在前后层按互补权重和 alpha-over 补偿分配透明度，上部主要在前、下部主要在后，减少重复变厚的边缘。
- 为八款发型分别配置发际线与等比尺寸；此前每个性别所有发型共用一个缩放系数及 0.345 的发际线高度。短束、低髻和披发现在分别对齐。
- 头部、身体、衣领配置及存档字段保持兼容。

本次调整渲染与配准，没有重画发型素材。造型是否符合用户期望仍需结合近景判断，不能由功能测试代替美术评价。
