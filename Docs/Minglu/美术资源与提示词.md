# 美术资源 v0.2

本轮使用内置 image_gen 工具生成，非CLI/API。生成图保存原文件，项目副本位于 Assets/Minglu/Resources/Minglu/Art。

- city-v02.png：1536×1024，城市底图。地图节点与文本由Unity绘制。
- portraits-v02.png：四列角色立绘图集。Unity按等宽UV显示，不对生成图进行裁切或重新绘制。
- 字体：复用工程已有 simhei.ttf；未新增外部字体。
- 界面线条、进度条、卡片和图钉：Unity原生UI绘制。
- 点击音：运行时生成短促音效；没有复用原英雄项目的人物配音。
