# 本轮问题排查与修复

检查范围：组织首脑主流程、任务筛选与定位、通知、读档、地区经营、人事展示、共用滚动控件，以及既有自动化运行日志。这里记录已定位的问题，不代表项目不存在其他缺陷。

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 点击通知前往任务，目标可能不可见 | 通知直接修改任务 ID，没有解除旧筛选 | 使用统一定位入口，清空筛选并回到顶部 |
| 读档后沿用旧任务选择与筛选 | 读取游戏状态时没有重置任务视图 | 清空旧任务选择、筛选，优先选可行动成员 |
| 底部建议和处理按钮去向不同 | 提示与导航对已授权任务的判断不同；全部安排后跳去经营 | 都优先处理未授权事项，全部安排后打开夜前检查 |
| 点击列表下方任务后选中卡片消失 | 选中项被排到首位，但滚动位置不变 | 查看、推荐、对比时安排回到列表顶部 |
| 身份门槛显示虚高 | 展示统计包含被捕和永久离队成员，规则要求可行动成员 | 展示与规则统一按可行动成员计数 |
| 长人物经历被截断 | 固定文本高度，不随记录增长 | 独立滚动详情，按实际文字高度布局，政策按钮保持固定 |
| 某些长通知仍被裁切 | 按字符数估计高度与实际字体换行不一致 | 使用实际文本高度布局 |
| 动态内容增长后没有滚动条 | 只在控件创建时检查长度 | 始终接入滚动条，按内容自动显示或隐藏 |
| 短内容增长后跳到底部 | 不可滚动区域的归一化位置被记成底部 | 不可滚动时统一记为顶部，增长后从头阅读 |
| 联盟信任已满仍显示发起按钮 | 缺少最大值状态表达 | 显示“信任已满 · 收益持续”；现有委托仍可查看 |

新增界面回归覆盖：旧筛选下通知定位、读档清理陈旧任务视图、长人事记录的实际高度。继续运行既有规则检查、完整模拟和授权/链条/事件/外观/存读档按钮流程。

本轮没有重新生成角色图像。外观部件是否在所有男女、年龄、服装组合下都自然，仍需要组合图视觉验收，不能用编译或规则测试代替。不同屏幕比例和长时间游玩的节奏也仍需后续人工验证。
