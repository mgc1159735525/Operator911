# 发型大小适配 v15.6

用户明确反馈的是大小不协调。本轮固定脸、头部、身体及衣领位置，只调整头发与脸型的尺寸关系。

## 修改
- 男女八种发型分别收小，参考脸型上比 v15.5 缩小约 6%～13%，短束收幅最大。
- 根据原始头像在 40% 高度处的实测太阳穴宽度，适配八种基础面容。宽脸获得相应增量，避免全部角色戴同一尺寸的发套。
- 围绕已校准的发际线锚点等比缩放，保持前发、后发及头皮遮罩使用同一个变换。
- 胡须、脸部五官、身体及存档格式不变。
