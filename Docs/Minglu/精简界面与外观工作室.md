# 精简界面与外观工作室

主界面保留当前目标、待办、成员选择、可用预算与执行入口。重复的关卡人数、累计送达、总额/预留预算和压力统计移入“组织概况”；完整能力、生活状态与身份成长移入“人物档案”。没有选任务时，右栏改为短卡片；选中任务后仍现场显示成功率、消耗与岗位冲突，避免把决策所需信息藏起来。

外观工作室分为“形象 / 五官 / 配色”，只展示当前组的分类；所有选项都有渲染缩略图。使用现有写实素材与已校准的头发、脖子、胡须锚点，本轮不全局改变人体比例。

功能：
- 半身/头部放大预览，显示原貌与当前预览；对比状态禁止直接应用，避免看到原貌却保存新稿。
- 每次修改可撤销/重做；还原恢复本次打开时的外观，也能撤销。
- 单项锁定只约束随机；随机保持当前性别，不影响能力或游戏随机序列。
- 女性不带隐藏胡须；五官组按性别显示合法选项。
- 3 个带缩略图的跨局预设槽；空槽不可读取，覆盖已有槽先确认；读取只更新预览，应用才写入角色。
- 关闭、取消和 Esc 统一检查未应用修改；编辑期间 F9 不会直接丢弃草稿。
- 从人物档案进入编辑后，应用或取消返回人物档案。
- 保存失败保留当前稿件并显示错误。

验证覆盖锁定随机、撤销重做、男女胡须、缩放与对比、预设存取与覆盖保护、负责人开局应用、人物取消不改变数据，以及精简后的两类详情弹窗。另运行组织原流程及规则模拟。
