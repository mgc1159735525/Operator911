# 明路·地下 UI与城市交互 v0.2

## 体验目标

玩家扮演坐在密报桌前的组织领导者。主要操作是选人、选地、签发行动、阅读后果。
每一个金色区域选择和按钮都对应可执行的操作，不把静态概念图当作界面交付。

## 视觉规范

- 基准画布1600×900，等比适配窗口；较宽屏幕居中显示，保留暗色边缘。
- 背景墨蓝 `#101C21`，面板 `#17262B`，分隔线 `#344248`。
- 金色 `#D5B778` 表示选中与主要操作；青绿 `#74B6A6` 表示恢复和情报；朱红 `#D47768` 表示暴露与被捕。
- 字体复用工程黑体。正文17—23逻辑像素；资源与风险不只用颜色区分，同时显示文字或数值。
- 不在游戏主界面显示导表路径、JSON版本等开发细节。

## 布局

顶部：游戏名称、行动成果、敌方压力、情报储备、回合、存读档、指南与菜单。

左侧248宽：同志名录。头像、姓名、身份、状态、当前行动、体力与暴露条。支持滚动，点击选择。

中央868宽：地图/组织联系/行动日志三种视图。

右侧404宽：所选地区档案、当前成员、人物详情入口、五类行动、行动风险预览、签发与撤回。

底部：当夜指令汇总、剩余AP、反馈消息、回合结算。结算前展示确认清单。

## 六区域

| 区域 | 定位 | 实際规则 |
|---|---|---|
| 西市 | 稳妥起步 | 基础风险和收益 |
| 文津书院 | 情报据点 | 侦察额外1情报，额外5暴露 |
| 北衙 | 高价值目标 | 成功需求+1、额外12暴露、破坏成果+4 |
| 东营 | 军需部署 | 成功需求+1、额外10暴露、破坏成果+3 |
| 城南古寺 | 隐蔽接头 | 基础风险和收益 |
| 东埠码头 | 风险换收益 | 额外8暴露、破坏成果+2 |

节点坐标与以上数值均可导表修改。区域节点显示执行人数和被捕人数；被捕地点沿用成员行动所在区域。营救必须在目标所在区域，选择目标时自动切换。

这是节点策略地图，不包含自由行走、道路寻路或区域占领。

## 可操作流程

1. 名录选人，地图选区。
2. 右侧选行动；营救会先展示被捕成员名单。
3. 查看骰子需求、模糊把握、体力和暴露代价，签发指令。
4. 可换人继续派遣，也可撤回某人的指令。每人一个行动，全组织AP受配置限制。
5. 封缄前确认全队安排；执行后先读夜报，再处理下一回合的密报。
6. 事件选项展示明确资源变化；无法支付时禁用，配置校验确保至少一条无成本出路。
7. 胜负页显示行动成果和成员结局，可回看日志或开启新局。

## 人物与资源

沈默、顾青、陈砚、林叔拥有各自立绘、表身份、小传、行动能力和上下线。被捕与失联头像变暗，同时显示文字状态。
目前采用固定立绘图集，不包含捏脸。图集按四等宽列显示，角色表可复用指定列。

点击音为运行时合成的短音，菜单可关闭。本轮未加入背景音乐或配音。

## 可用性

- F5存档，F9读档；Esc关闭普通弹窗或打开指南。
- 角色、日志、夜报和营救名单可滚轮滚动。
- 准备阶段可以修改指令；结算需要再次确认。
- 存读档异常显示消息；独立v2存档不覆盖v1灰盒存档。
- 新局更换随机种子，读档恢复原随机状态。
