# 地区情报交通 v0.8

玩家担任新京地区地下工作的最高负责人。玩家本人不占外勤名额；接收、外送与建立联络由指定成员执行。长期潜伏联络是独立角色名录，不挤占可操作外勤队伍。

## 当前可玩流程

1. 新开「新京二十夜」战役，自动进入情报交通，首份密件已经出现。
2. 左侧选择成员，点击密件的「接收密件」，封缄并结算一夜。
3. 接回后可查看正文；下一夜选择同一人或另一成员「外送情报」。
4. 外送结算获得回执与情报、成果、银两，降低来源区热度。收益只结算一次。
5. 累计送达两份后，在潜伏联络页派人支付20银两接入第二条线；四份后可接入第三条。

初始联络为都督府机要书吏「渡鸦」，后续可接入将军府随侍「秋雁」和军需账房「青舟」。三类密件分别涉及搜查名册、军议调令与军需账目，具有不同回执和奖励。现阶段模板会循环使用。

## 调度与风险

- 每项指令占用1行动点、12体力，并消耗现有组织规则规定的精神；接收地点在来源区，外送在西市交通站。
- 暴露增量为交通基础暴露6 + 地区风险 + 城市热度/支持修正，之后仍接受现有搜查与被捕判定。
- 一人一夜执行一项工作；同一密件不能交给两人重复处理。可在右侧撤回，或改派其他行动。
- 接收与外送不能同夜完成。第N夜结束失效的密件可以在第N夜外送，但该夜才接收就来不及外送。
- 指令签发时预留经费，与招募共享预算；结算时扣除。扩展每夜最多一条线。
- 初始来源从第4夜结束开始继续产出，默认后续间隔2—4夜；新来源建立3夜后开始产出。间隔为确定性节奏，不是随机概率。
- 外勤成员临时潜伏产生的消息也进入本系统。潜伏被识破时未接回的消息失效，已入站的密件保留。

## 界面与保存

情报交通包含待办密件、潜伏联络、回执与失效三页；密件详情在接回前隐藏正文，地图位置按钮可定位相关区域。城市区域档案显示待接数量并提供入口。组织页的递送入口指向新模块。

新战役默认启用；八夜试玩保留旧组织递送模式。当前局使用 `minglu-run-v8.json`，不迁移或覆盖v7。保存包含密件状态、已获回执、来源产出时钟、待执行指令与配置快照。修改配置只影响新局。

## 配置入口

Unity菜单：`Minglu > 情报交通配置`。支持JSON导入预览、校验、导出及备份后发布。

运行文件：`Assets/Minglu/Resources/Minglu/Config/courier_config.json`。

| 字段 | 用途 |
| --- | --- |
| cycle / lifetime | 基础产出间隔 / 密件有效夜数 |
| expandCost / expandDeliveries | 接入银两 / 每条新增线所需累计送达步长 |
| staminaCost / exposure | 每项交通工作的体力消耗 / 基础暴露 |
| sources | 潜伏者ID、代号、岗位、所在地区；active/next/produced由运行时维护 |
| templates | 标题、正文、回执、情报/成果/银两/热度奖励 |

规则入口 `CourierRules`；界面 `CourierUI`；验证菜单 `Minglu > 验证情报交通`。

## 当前边界

这是已接入原有战役的基础情报经营循环，并非全部谍报系统完成。交通采用每阶段一夜的抽象结算，有效指令会完成，再承担整体搜查风险；没有行进路线、途中拦截、护送战斗或自动重复派遣。长期潜伏角色尚无忠诚、反间、身份危机与独立人物事件。模板奖励也不直接改写后续主线任务。最终胜利仍遵循现有二十夜战役的主线要求，单纯送情报不能替代最终任务。
