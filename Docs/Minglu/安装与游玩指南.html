明路·地下

你是地区负责人。你安排人员、建立联络网、授权目标；成员负责具体行动。

直接玩游戏不需要安装 Unity、Git 或 SourceTree。使用 Windows 10/11 的64位电脑，双击安装包即可。

安装与更新

  1. 关闭旧游戏，双击 MingluSetup.exe，选择“下一步 → 安装”。
  2. 默认安装到 D:\Games\MingluCity，安装后从桌面“明路·地下”打开。
  3. 以后更新同一安装目录即可，无需每次建立新的游戏文件夹。不要只移动 EXE，运行需要同目录的数据文件。

直接运行地址：D:\Games\MingluCity\MingluCity.exe。存档位于 %USERPROFILE%\AppData\LocalLow\DefaultCompany\Operator911，更新程序不会删除这些文件。

第一次行动

  1. 新局：建议先选择“初探”和二十夜完整经营。新局页列出最终成果、送达和身份要求；八夜是短局挑战，并非自动更简单。成员的姓名、外观、身份和能力随机。
  2. 第一夜：跟随底部“当前重点”，打开一项入门任务。先看目的和期限，再比较负责人。选择常规方案并授权，返回地图后结束今夜。看档案、调整方案和取消授权不会推进时间。
  3. 从第二夜建立联络网：选择在敌方机构任职的内线，再选接头人和交通员，三人不能重复。启用后成员自动工作。缺少内线时，先在人事档案建立机构任职任务。
  4. 看清每夜推进：内线观察产出，下一夜才能接头，再下一夜才能外送；每环都有独立骰子判定。链条详情显示今晚哪个岗位有工作、哪个在等待。失败可能延后，只有送达才增加库存情报。
  5. 继续经营：完成当前阶段要求，保持成员生活与岗位轮换，决定是否增加第二条链、接纳新人或发展地方盟友。对照主界面的阶段目标安排下一步。

一次授权需要看什么

信息含义
时间多阶段任务需要多次成功。“今夜必须开始”按剩余阶段计算；只显示本阶段概率，不保证整个任务完成。
负责人能力决定骰子数量，每骰4—6为一次成功。优先比较身份准入、当前状态和今晚是否承担链条工作。
方案常规不追加经费；筹备每次4银换加骰与较低暴露；紧急推进增加骰子但提高暴露和压力。情报支援每次使用1份已送达情报。
调查调查占用一夜，成功后该目标执行加骰并降低暴露。它不完成任务、不产生库存情报；简单任务可直接执行。
机会成本一人一夜只做一项地下工作。已授权任务优先，相关链条岗位可能等待；留意连勤、补助和剩余夜数。

授权先预留预算，结束今夜时才掷骰并支付。失败也会消耗投入；撤回尚未执行的授权会释放预算。查看任务可知道失败后还能否重试。

人员、交接与安全

  • 人事档案中先预览随机新人的能力、机构身份与生活牵挂，再决定是否花12银接纳。每名在岗成员每夜需2银补助；反复开关预览不会重抽新人。
  • 空闲或生活优先时处理本职工作、恢复状态并培养表身份；地下任务和成功的链条工作积累相应能力经验。身份等级与地下能力是两种成长。
  • 正常换岗保留待接、中继情报与已等待时间，换后链条暂停，核对后重新启用。若旧成员失陷，交接弹窗会说明对应情报损失。暂停不会停止情报老化。
  • 暴露达到预警线后应安排休养。成员被捕会产生有期限的营救任务；救回后仍需恢复岗位。追查达到据点阈值时，会出现需要决定的撤离事件。
  • 普通完成、升级和送达结果合并为夜间要报，详细骰面可在值夜报告展开。突发事件的选择会改变成员、经费或链条状态，请先读清后果。

界面与存档

城区地图始终是桌面中心。左侧按钮打开任务簿、联络网、人事档案、值夜报告、地方事务。右上“设置”集中提供保存、读档、指南、声音与显示、返回菜单及退出。

Esc 返回上一层；F5 保存；F9 读取；滚轮翻阅档案。新局、夜间结算与事件选择后自动保存。旧存档保留原有本局目标，新局使用新目标规则。

人物外观

从主菜单或人事档案进入“人物绘卷”。在“形貌、五官、设色”之间切换，每个部位占一行；点击当前款名或右箭头换下一款，左箭头返回上一款，末款与首款循环相接。眼睛、眉形、鼻形、嘴形和耳朵各有8款，男女发型各有8款，男性胡须有7款，另可选择“无”。当前序号和总数显示在款名旁；发式、面容和服装可逐项搭配。“随机时保留”让对应部位不参与随机，仍可手动切换。

头发与胡须共用“须发色”，保持配色一致。选择长者面容时默认银白；随机长者以银白为主，也会出现霜灰。若已保留须发色，更换面容或随机形象都会沿用该颜色。你仍可手动选择乌黑等颜色；读取预设和旧存档不会强制改色。“设色”中的“按年龄配色”可主动恢复长者银白、其他年龄乌黑，这次操作也可撤销。

左侧实时预览完整搭配，“查看面容”可放大检查。撤销、重做及“对照原貌”帮助比较修改；收藏预设可跨局复用。预览不会直接改变角色，点击“保存为开局外观”或“应用并保存”后才生效；取消时可以放弃草稿。外观不影响角色能力。

项目与安装包（开发使用）

项目目录：D:\UnityProjects\Operator911，Unity版本：2022.3.62f3c1。SourceTree选择“添加”并填入项目目录即可查看Git记录。只有配置远程仓库并成功推送后，才算完成远程备份。

在项目中运行 Tools\Installer\Build-Installer.ps1，会验证、构建游戏并生成固定的 Builds\Installer\MingluSetup.exe。构建已完成时可加 -SkipGameBuild。需要 Unity 和 Inno Setup 6。

当前为持续开发的可玩版本。安装包、实际游戏、源项目各有固定目录；存档独立保存。
