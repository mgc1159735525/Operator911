明路·地下

安装、第一次游玩、更新和项目备份，一份指南即可。

玩游戏只需安装包，不需要 Unity、Git 或 SourceTree。当前是开发试玩版，需要 Windows 10/11 的 64 位电脑。

一、三步安装

① 双击 MingluSetup.exe② 下一步 → 安装③ 完成 → 开始游戏
  1. 先关闭正在运行的旧版游戏，再双击安装包。
  2. 保留默认安装目录即可。安装程序为当前用户安装，不需要管理员权限。
  3. 安装完成后，勾选“启动明路·地下”。以后双击桌面上的“明路·地下”即可进入。

默认位置：%LOCALAPPDATA%\Programs\MingluCity。安装时可选择其他目录。请保留完整安装目录，不要只移动里面的 EXE。

二、第一次玩：你是负责人

你的工作是挑目标、分配成员、安排联络网。具体接头和行动由成员自行执行。

  1. 开始新局：从主菜单进入新局，查看左侧简报中的目标进度和顶部剩余夜数；前三夜可跟随三步清单。
  2. 先配联络网：新局直接进入“联络网”。点击岗位，在候选弹窗中比较骰数和成功率，内线必须选在敌方政务署、税务署、巡防局或驻军司令部任职的成员；接头人和交通员可为民间成员。安排三名不同成员，再点“启用此线”。下方会预告今夜执行或等待的原因。
  3. 挑一项任务：回到“任务簿”，点击“查看任务”，再点击“推荐人选”，检查右侧能力、岗位冲突和成功率。
  4. 配置行动方案：点击右侧“调整投入”。常规不追加预算；筹备花钱增加骰数；紧急增加风险。情报支援可额外增加一颗骰子。第一次建议先做要求低的任务，保留一部分经费。
  5. 授权：确认收益、消耗、失败后果与截止时间后授权。授权只预留资源，撤回会释放；推进一夜后才实际执行。
  6. 结束今夜：点击右下“签发指令／结束今夜”，在确认页检查安排。阅读事件与执行报告，根据新情况调整。报告默认显示上一夜结果与原因，可切换到其他夜或展开全部骰面；结束后也可打开复盘。派去执行任务的链条成员当晚会优先执行任务，对应链条岗位等待。
  7. 持续观察：安排休息、维护表身份与生活，避免让成员长期过劳。失败后可在截止前重新授权；情报生产、接头、外送需要逐步完成，不会一夜走完整条链。
情报来源：只有敌方机构任职者可担任内线，产出待接情报；接头、外送完成后才增加可用情报。普通任务、日常生活和主动发现不直接奖励情报。开局保证一名随机机构内线；扩大来源时，到“人事档案”选择成员，点“建立机构任职”，选择机构，随后由本人执行任职任务。成功后配置联络网。旧存档中没有任职来源的链条将暂停并清除待传积压，已送达的情报与战绩保留。

从地图查看任务

打开“城区地图”，点击一个城区，在右侧查看当地待办、截止时间和区域暴露。点击“查看任务”才进入任务签发页；选区本身不会授权、扣钱或推进时间。空城区可通过右侧入口查看地方事务或联络网。签发栏直接列出预算、情报与成员消耗；招募等操作把费用放在按钮右端。

外观与人物档案

右侧“人物档案”查看能力、身份和生活；“组织概况”查看负责人立绘、阶段要求和预算。概况内可编辑负责人外观。外观工作室支持半身/头部预览、分类缩略图、撤销重做、锁定随机与三个预设槽；只有点“应用”才修改角色。撤销会保留正在编辑的分类。

三、保存、更新与卸载

  • 退出前点击游戏中的“保存”或“保存返回”。再次进入使用“继续／读取”。
  • 以后直接运行新的同名 MingluSetup.exe，覆盖原位置即可。无需按版本安装多份。
  • 存档目录：%USERPROFILE%\AppData\LocalLow\DefaultCompany\Operator911。将此目录整体复制到其他位置即可备份。开发版尚不承诺所有未来改动都兼容旧存档。
  • 卸载：Windows 设置 → 应用 → 明路·地下 → 卸载，或开始菜单选择“卸载明路·地下”。卸载程序不会主动删除上述存档目录。

四、常见问题

  • 找不到入口：搜索开始菜单中的“明路·地下”，或打开安装目录中的 MingluCity.exe。
  • 窗口显示不完整：尝试按 Alt+Enter 切换窗口模式，再调整窗口大小。
  • 任务不能授权：看方案页下方原因，检查成员状态、身份等级、剩余阶段和期限、预算与情报是否已被其他任务预留。
  • 情报没马上送到：看链条各环节、执行报告、事件休整与任务占用。生产失败和岗位等待都会产生延迟。
  • 无法启动或闪退：重新运行安装包修复缺失文件。将存档目录中的 Player.log 和问题截图发给开发者。
  • 系统提示发布者未知：当前安装包未作商业代码签名。核对文件来源和 SHA-256，不要关闭系统防护。

新功能：安全预警与地方事务

  1. 打开“地方事务”，可发起联盟委托或街坊互助。发起不花资源；进入任务簿，点“比较人选”，再选方案授权。联盟需两次成功，每阶段都要重新授权。
  2. 主界面左上显示追查和民心。联盟信任达到门槛后提供持续收入或能力加成，经营页会显示是否已生效。
  3. 成员高暴露会先预警。用“处理下一项”定位成员，安排生活优先，并让其他成员接替岗位。生活优先会立即撤回该成员的任务并释放预留预算；休养每夜降低10暴露，极高暴露仍可能无法及时脱险。换岗如会丢失积压，弹窗会列出数量；取消不会修改原安排。
  4. 被捕后通常生成两阶段营救；倒数第二夜被捕时改为单阶段紧急营救，最后一夜不再生成来不及执行的任务。注意任务标明的阶段和截止夜。营救成功后成员先休养，原链条需要你检查后重新启用。
  5. 据点追查达到门槛时，选择花钱保留情报转移，或销毁中继情报免费撤离。两种方案都会暂停当夜链条，已授权任务仍执行。
  6. 推进一夜前，检查确认页的到期任务、岗位冲突和高暴露成员；这两块列表都可滚动。

五、用 SourceTree 管理项目（仅开发需要）

  1. 打开 SourceTree，选择“添加”，路径填 D:\UnityProjects\Operator911。也可以直接打开已有的 Operator911 标签。
  2. 在“文件状态”查看变更，确认后暂存需要保存的文件，写一句改动说明，再点“提交”。提交是本地历史记录。
  3. 配置远程仓库并完成账号授权后，点击“推送”，选择 main 分支。推送成功才代表远程备份完成。
  4. 换电脑时使用“克隆”，输入私有仓库地址，再用 Unity Hub 打开克隆后的项目，编辑器版本为 2022.3.62f3c1。

源码、美术资源、配置表与 .meta 文件会保存在仓库。Library、Builds、日志、测试截图与 node_modules 不提交；Unity 会重建缓存，工具依赖按对应 package-lock 安装。

六、重新生成安装包（仅开发需要）

在项目中运行 Tools\Installer\Build-Installer.ps1。需要 Unity 2022.3.62f3c1 和 Inno Setup 6。脚本先检查和构建游戏，再生成固定路径 Builds\Installer\MingluSetup.exe。已有最新构建时可使用参数 -SkipGameBuild。中文语言文件来自 Inno Setup 官方仓库。

本指南随安装包一同安装，可从开始菜单打开。安装包不等于源码；安装游戏与管理项目是两个独立步骤。
