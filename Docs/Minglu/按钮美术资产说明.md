# 按钮美术资产

沿用印刷档案界面：克制的铁锈红、暖纸色、炭灰绿，以及低对比印刷颗粒。字、图标和业务状态不烘焙进底图，避免缩放后文字模糊。

## 交付内容

- 游戏切图：`Assets/Minglu/Resources/Minglu/UI/PrintButtons/`。
- 原始透明图集：`ArtSource/UI/PrintButtons/print_buttons_source.png`。
- 生成提示词及修订记录：`ArtSource/UI/PrintButtons/generation-prompts.txt`。使用内置 image_gen。
- 裁切坐标和导入参数：`ArtSource/UI/PrintButtons/sprite-manifest.json`。

| 文件前缀 | 用途 | 字色 |
| --- | --- | --- |
| `button_primary_` | 开始、签发、确认应用 | 暖白 |
| `button_paper_` | 纸面弹窗与表单中的普通按钮 | 深灰 |
| `button_dark_` | 暗色界面的普通按钮 | 浅米白 |

每类均有 `normal`（普通）、`hover`（悬停）、`pressed`（按下）、`selected`（选中）、`disabled`（禁用）五个 PNG，共 15 张。禁用态降低饱和度；选中态同时增加边线，避免只靠颜色区分。

## Unity 接入

导入为单张 Sprite，透明通道保留、双线性过滤、无 Mipmap、无有损压缩、Clamp。九宫格边距为四边 16 源像素，PPU 为 300；按实际按钮长宽拉伸，保护边缘线条。

`PaperUI.cs` 的普通与主要按钮使用 SpriteSwap 自动切换五态；主要按钮使用 0.82 中性乘色控制亮度，配暖白文字。按钮选中参数和键盘焦点均有对应图。素材不完整时整组回退原有绘制，避免某一状态按钮消失。

目录、文字链接、头像选择和地图标记继续使用各自的轻量样式。主菜单文字按钮清除 Sprite 与 overrideSprite，避免残留按下或禁用底图。

源文件到切图是无损裁切，不重画、不缩放、不改 alpha。PNG 透明区域可能保留隐藏 RGB，判断透明度应看 alpha，不能只看忽略透明通道的预览。

## 维护与验证

Unity 菜单：`Minglu → 美术 → 导出印刷按钮切图`。更换图集尺寸或排布时先更新 `PrintButtonAssetTools.cs` 的格子区域；导出会校验尺寸、内容范围、张数和导入参数。

独立交互验证参数：`--button-art-only --minglu-capture <截图路径>`。验证实际 SpriteSwap、九宫格、射线命中、单次点击和禁用拦截，同时输出游戏内按钮状态预览；使用隔离存档。
