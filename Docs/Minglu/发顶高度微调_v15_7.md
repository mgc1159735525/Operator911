# 发顶高度微调 v15.7

按发顶略高的理解进行小幅调整。保留 v15.6 的宽度和脸型适配，发际线作为固定轴，仅将轴以上的发顶高度压缩 4%～8%；轴以下的鬓角、披发长度不变。帽款收幅最小，短束收幅较大。

实现采用渲染时局部纵向取样，前发、后发、头皮遮罩使用相同的 CrownHeight 参数和 HairAnchor 锚点；取样不得越过当前图集格，避免带入其他发型。胡须不应用该变换。没有更改头部、衣服或保存格式。
