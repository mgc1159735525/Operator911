# 写实外观修复 v0.15

## 改动

- 五官改为当前基础脸上的局部 UV 塑形。眼、眉、鼻、嘴、耳朵分别提供原生与三种轻量形状变化，不再从别人的完整脸上取像素覆盖，因此不会引入其他年龄的皱纹和肤色。它是二维局部塑形，不是三维捏脸，也不再把年龄供体称为独立五官素材。
- 新增 `PortraitLayout`：逐脸五官定位、发型源区域与锚点、原比例缩放、逐衣领高度。UI 大小只影响整体缩放，不再改变头发本身宽高比。
- 删除 `NeckUnderCollar` 的8像素皮肤拉伸补丁。使用基础脸自带的完整颈部，由各套衣服的领口覆盖接合。
- 前后发分开绘制，下垂长发在身体后方；前发下缘渐隐，避免沿下颌水平切断。修正男性披发中心偏移；增加发髻和帽子的顶部留白。
- 编辑器、局内档案、成员名录、随机成员采用同一渲染路径。随机五官使用有界局部塑形，发色按基础脸年龄组协调。
- 新增 `portraitVersion=15`。旧外观保持基础脸、性别、衣服、发型和颜色；旧的年龄供体五官索引转为原生五官，避免把旧含义错误解释成新形状。转换使用副本，不直接覆写旧预设文件；在应用或保存预设时才写入。

## 构建与使用

运行 `Builds/MingluCity-v15/MingluCity.exe`。本版仍读取组织首脑模式的 v14 对局存档，无需为外观修复重开。旧版可执行文件保留。

## 验证方法

- `PortraitRepairVerification.BatchDeliver` 检查200个随机外观、旧数据迁移与重复迁移稳定性、男女8脸×4发型的等比例定位、着色器编译并构建。
- `--portrait-repair` 使用实际 UI 点击五官选项，检查保存与预设；游戏渲染输出64组半身与名录组合，另有12组随机肤色、衣服、五官、胡须组合。五官像素变化检查仅表示功能生效，画面仍需逐图查看。
- 组合页将同编号脸与服装配对，再遍历发型，并非穷举所有脸×衣服×发型×颜色组合。
- 图片输出位于 `outputs/portrait-v15`，构建和实机日志位于 `Logs/portrait-v15-*`。

## 保留的限制

仍使用原有写实图集；没有在本轮生成更多面容或更换整个美术风格。五官变形幅度刻意限制以保护皮肤纹理，不能任意拖动或生成全新表情。既有图集边缘与细发丝质量仍受原始像素分辨率限制。
