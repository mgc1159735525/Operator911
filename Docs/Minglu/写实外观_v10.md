# 写实男女外观 v0.10

## 使用

主菜单「负责人外观」或人物档案「自定义外观」，选择写实立绘，切换男性/女性，设置面容、服装、背景、肤色与衣色。随机组合保持当前选择的性别。预设、应用、取消和恢复原貌继续有效。

写实素材为原创生成绘制：男女各4套年龄面容、各4套服装，按头部/服装分层组合。写实面容包含配套发式，不提供独立眼鼻嘴编辑；旧版13类五官编辑保留在「经典组合」中，旧存档不会被强制转换。肤色通过头部整体色调调整，衣色通过灰色服装层着色，不是生理材质仿真。

## 随机角色

新局的3位招募候选人使用新外观生成器，有男性也有女性，并显示头像与性别。候选人姓名也按性别从姓名池选取；身份岗位及能力规则保持原有配置。

生成由对局种子和候选人ID推导独立外观种子，不消耗任务随机流。当前候选人ID交替分配性别，确保小规模候选池男女都有；面容、服装与配色由外观种子决定。招募成功时复制候选人的外观，不重新抽取。存档同时保留候选人与成员外观。

未来增加随机角色时调用 `AppearanceRules.ForRecruit(seed,id)` 或 `AppearanceRules.Randomize(seed,sex)`（sex=-1时随机性别），将结果存入角色的 `appearance`。现有固定剧情成员继续保留原立绘，玩家可手动换成写实外观。没有新增自动无限刷新候选人的玩法。

## 素材和实现

- 素材：`Assets/Minglu/Resources/Minglu/Art/realistic-atlas-v10.png`，1254×1254，RGBA透明图集。
- 来源：内置 image_gen 工具生成，未使用外部游戏立绘。原始输出已复制入项目。
- 渲染：`RealisticPortraitUI.cs`。基于图集校准行边界，运行时合成头像与服装；保留原始透明通道，不修改源图。
- 数据：Appearance新增style（0经典/1写实）与sex（0男/1女）；保持13项旧索引，兼容现有v8对局及v1档案文件。
- 导入：`RealisticPortraitImport.cs`，保留透明度、原始尺寸，无mipmap和有损压缩。
