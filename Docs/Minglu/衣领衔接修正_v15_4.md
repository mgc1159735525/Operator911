# 衣领衔接修正 v15.4

## 本轮定位
v15.3 的颈部采用固定矩形裁切，颈部轮廓容易出现直边。旧头像在脖颈底端还有外扩尖角，透明混合过晚时会露在立领外侧。所有衣服以同一个 316 闭合高度对齐，也让立领与交领暴露相同长度的脖颈。

## 修改
- 男女八款衣服分别配置衣领闭合高度，立领提高、交领保留领口空间；头和发型位置不动。
- 修正男女颈部素材中心，使用完整取样范围和柔边轮廓遮罩，消除矩形裁切的生硬竖边。
- 在下巴以下收去旧脖颈的外扩尖角，提前平滑过渡到颈部底层。
- 服装继续在脖颈上方绘制，覆盖颈根，不改变存档数据或外观选项。

游戏截图输出 outputs/portrait-v15.4；验证记录 Logs/portrait-v15.4-build.log 和 Logs/portrait-v15.4-ui.log。
