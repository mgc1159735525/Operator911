制作工具 · Unity 2022.3.62f3c1 · 2026-10-13

人物部件校准器

直接看着游戏使用的立绘，调整部件的位置、宽高、旋转和眼眉间距，再把结果保存为游戏读取的 CSV 配置表。

开始调整可调部件应用范围配置表让游戏生效

这是 Unity 内的制作工具。已安装的游戏提供款式选择；部件校准在项目编辑器中完成。校准修改共享美术布局，不会修改玩家的能力、任务、夜数或旧局通关条件。修改后符合规则的旧角色和随机角色都会采用新布局。

第一次调整：先只改一个组合

  1. 在 Unity Hub 打开项目 D:\UnityProjects\Operator911，使用 2022.3.62f3c1。等待导入和编译完成；如果正在 Play，先停止运行。
  2. 在 Unity 顶部菜单选择 Minglu → 美术工具 → 人物部件校准器，或按 Ctrl + Shift + P。备用入口为 Tools → Minglu → 人物部件校准器。
  3. 左侧选择需要检查的性别、完整头部和部件款式，再选择要调整的部件。右侧“应用范围”先用 当前头型 + 当前款式，避免试调影响其它组合。
  4. 在中央拖动选中框改变位置；拖右下角方块改变宽高，按住 Shift 等比缩放。也可以直接在右侧填写 X / Y、宽度倍率、高度倍率和顺时针角度。建议每次只改一个参数，先对齐眼睛，再调整鼻子、嘴、胡须，最后检查颈部与衣领。
  5. 调整眼睛或眉毛时，使用右侧 双侧间距。间距与部件自身宽度是两个参数：眼睛偏大时改宽高；两眼太远时改间距。点击预览框取得焦点后，方向键每次微调 1，按住 Shift 每次微调 10；正在输入数字时方向键不会移动部件。
  6. 点击 面部放大、参考线 或 对照默认 检查结果；“对照默认”显示空校准表的原布局，关闭对照后继续调整。再切换临近头部和款式检查；只适合当前组合就保留具体范围，确认适合一组角色后再扩大范围。
  7. 满意后点 导出 CSV 保存备份，再点 保存到项目并生效。这会更新 Unity 项目的共享表；完成构建和覆盖安装后，已安装游戏才会使用这些调整，详见让游戏生效。

左侧 随机预览 只随机校准器中展示的人物，不会随机真实队友；复制组合 JSON / 粘贴组合 JSON 便于复查同一个外观组合，这份 JSON 只描述所选款式与配色，不是校准 CSV，也不是玩家进度。

能调整哪些内容

部件可调整内容需要注意
完整头部 · Head头部整体位置、宽高、旋转；五官和附着饰物跟随头部组。头发、脸廓、耳朵已经画在同一张头部原画中，不能单独移动发丝、耳朵或改变脸廓。切换完整头部可更换这套原画。
颈部 · Neck颈部补片的位置、宽高、旋转。头部原画本身还含部分颈部。补片调整用于衔接衣领，不能自动重绘肩颈结构。
眼睛 / 眉毛 · Eyes / Brows整对位置、宽高、旋转，以及左右间距。左右采用分片显示，改间距不会把眼睛本身同时拉宽。左右形状仍来自所选款式。
鼻 / 嘴 · Nose / Mouth各自位置、宽高、旋转。嘴的位置与胡须需要一起检查；不要只看鼻尖，鼻根与眼窝的关系同样重要。
胡须 · Beard每款胡须的位置、宽高、旋转。只在男性所选胡须非“无”时显示。缩放与位移可以配准，不能补画缺少的毛根或改变原图的光影。
服装 · Outfit服装独立位置、宽高、旋转。服装不会随完整头部一起缩放。头身比例改变后，检查衣领是否吞掉脖子、肩宽是否自然。
饰物 / 远侧饰物 · Adornment / AdornmentFar眼镜、饰物主层及远侧耳饰的位置、宽高、旋转。远侧层只在含远侧耳饰的款式中显示。选择“无”不会生成可调整的可见部件。

数值怎么理解

所有数值以一张 400 × 600 的立绘画布为基准，和 Unity 窗口当前缩放无关。X 正数向右，Y 正数向下；例如 dx=-3, dy=-2 表示向左 3、向上 2。宽高倍率 1 是原尺寸，0.9 是 90%，1.1 是 110%。旋转按顺时针角度计。眼眉间距正数拉开、负数收拢；普通单部件的相互间隔用各自 X / Y 调整。

应用范围：一个人还是一组人

每行配置由“性别 + 头部 + 部件 + 款式”确定。没有配置的组合使用原布局；一行只覆盖同一性别，男性调整不会直接影响女性。

优先级头部 / 款式适用情况
1 · 最高具体头部 / 具体款式只修一个不协调的组合，例如男性 0 号头的 2 号眼。
2具体头部 / 所有款式（variant=-1）这个头部的整类部件都需要统一移动。
3所有头部（head=-1）/ 具体款式某一款素材在该性别所有头部上都有同样偏差。
4 · 最低所有头部 / 所有款式为该性别的整类部件设置通用布局。

优先级是覆盖，不是相加。一个组合只采用命中的最高优先级行；“当前头部、所有眼睛”的规则优先于“所有头部、某款眼睛”。删除具体规则后，会退回较通用的规则；将具体规则设为原倍率和零偏移则会用原布局覆盖通用规则。这两种操作的结果不同。

导出的 CSV 是什么

游戏项目表位于 Assets/Minglu/Resources/Minglu/Config/portrait-calibration.csv。使用 UTF-8 编码，导出文件带 BOM，方便 Excel 或 WPS 识别。表头、列顺序与部件英文名不要修改，小数使用英文句点。

sex,head,part,variant,dx,dy,scaleX,scaleY,spacing,rotation
0,0,Eyes,2,-3,-2,0.95,1,-4,0

这条示例表示：男性 0 号完整头部、2 号眼睛，向左 3、向上 2，宽度为原来的 95%，高度不变，左右间距缩小 4，不旋转。示例仅说明格式，并非推荐的美术参数。表内索引均从 0 开始；sex=0 为男性，sex=1 为女性。头部与颈部的 variant 固定为 0，或使用 -1 通配；具体头型由 head 决定。

列含义与范围
sex / headsex 为 0 或 1；head 为 0～11，-1 代表该性别所有头部。
part / variantpart 必须使用上表中的英文部件名。眼、眉、鼻、嘴、服装款式为 0～7；男性胡须为 0～7（0 为无），女性胡须只有 0；饰物为 0～3。variant=-1 表示该部件所有款式。
dx / dy位移。dx 范围 -400～400，dy 范围 -600～600。
scaleX / scaleY宽 / 高倍率，范围 0.1～3。
spacing仅 Eyes / Brows 使用，范围 -100～100；其它部件必须为 0。
rotation顺时针角度，范围 -180～180。

重复键、缺列、未知款式、非有限数值或越界值会使整次导入失败。先修正提示中的行，不要删掉表头。合法范围仅保护数据与显示计算；数值合法并不表示人体比例自然。

保存表格，然后让原游戏生效

  1. 导出备份：点“导出 CSV”，把当前校准导出到自己选定的文件。备份可以再次导入编辑；仅导出到外部文件不会更新项目表或已安装游戏。导出不能绕过“保存到项目并生效”直接覆盖项目表。
  2. 保存项目表：点“保存到项目并生效”，将确认后的校准写入项目的 portrait-calibration.csv。成功后 Unity 编辑器和下次 Play 会使用新表。重新打开校准器，检查刚才的组合仍然正确。
  3. 验证并构建：使用项目固定交付流程 Minglu.EditorTools.PresentationVerification.BatchDeliver。它会验证后构建 Builds/MingluCity/MingluCity.exe。
  4. 生成与覆盖安装：按项目的固定安装包流程生成 Builds/Installer/MingluSetup.exe，关闭原游戏，覆盖安装到 D:\Games\MingluCity。
  5. 最后看游戏：重启游戏，分别打开人物绘卷和成员档案。检查大立绘与小头像，确认实际使用新表。无需重新开局或删除存档。

CSV 是随构建打包的制作配置。修改项目表后，已经打开的旧 EXE 不会实时读取磁盘表，也不需要把 CSV 放进玩家存档目录。一般玩家只需要安装更新后的游戏。

撤销、恢复与导入失败

底部“撤销 / 重做”可以回退调整和导入。“本范围恢复默认参数”在当前范围写入零偏移、原倍率；“移除本范围配置 · 使用继承值”删除这条规则并重新采用较通用的规则。调整共享范围时，如果预览人物有更具体的规则，右侧会提示先处理那条规则；不要反复拖动一个已被覆盖的通用值。

校准器将工作草稿保存在项目 Library/Minglu/PortraitCalibrationDraft.json，重新打开时尝试恢复。它不是玩家存档，也不替代 CSV 备份；清理 Unity 的 Library 目录会丢失这份自动草稿。关闭有未保存修改的窗口时，按 Unity 提示选择保存、丢弃或取消；丢弃会回到当前项目表。

导入无效文件会保留原草稿并给出原因；导出或保存失败时，先处理提示中的路径 / 权限问题，再重试。若项目 CSV 在打开窗口后被其它工具修改，校准器会阻止覆盖：先导出自己的草稿备份，再“导入 CSV”选择项目当前表，核对后继续调整。这样不会无提示覆盖外部更改。

调整时的检查顺序

  1. 先确定头身比例：固定头部和服装，调整完整头部与颈 / 衣领。不要先把鼻子移到一个尚未确定的脸上。
  2. 先整体，再局部：看眼线、鼻底、唇线的关系，再调单款器官。保持一张脸的朝向与光源一致。
  3. 整身和局部都看：放大时细节清楚不代表头像自然；小头像也不能证明颈部衔接正确。
  4. 改一款，验相邻：至少比较青年与长者、无须与带须、眼镜与无饰物，再决定是否扩大应用范围。
  5. 保留可回退文件：确认一轮后导出 CSV，并用 Git 记录项目表。不要用覆盖真实存档的方式测试外观。

校准器改善的是部件配准效率。原画透视、皮肤过渡、头发与脸廓的一体结构仍属于美术问题；这个工具上线不等于所有角色已经自然、也不等于商业美术验收完成。
