# 弹窗减密与任务签发

中央常驻城区地图。左侧仅放任务簿、联络网、人事档案、值夜报告和地方事务入口，以及阶段目标和下一步；顶部显示夜数与关键资源，底部保留「处理下一项」「结束今夜」。五类业务统一在弹窗内处理，关闭或按 Esc 回到地图。人员名册只在人事弹窗中出现。右上仅保留「设置」，其中集中保存、读取、指南、声音显示、返回主菜单和退出。

## 阅读顺序与留白

业务弹窗采用 32 号主标题，顶部夜数与资源使用 22–25 号字。正文和工具组以 28 像素内边距对齐，分组之间保留更大的空隙。详情、返回和编辑入口弱化，选项用下划线或边框标识，不为每个按钮都添加重边框。

第一夜没有有效联络链时，「处理下一项」是主要操作；配置完成后强调「结束今夜」。任务弹窗突出签发，外观编辑突出应用。预设空槽突出保存，有内容的槽突出读取；事件弹窗按可用预算突出当前可执行的稳妥选项，并保留另一个选择及其后果。城区档案按实际任务数调整高度，空态不再留下整页空白。

修正新局「情报先行」的说明与收益不一致：组织初始化原本会清除承诺的初始情报，却保留全员暴露代价。现在改为追加 12 银两联络经费、全员暴露 10；情报库存仍从零开始，必须通过机构内线及传递链取得。指挥规则回归同时检查经费收益和无法绕过传递链。

## 任务簿

任务卡只显示标题、地点、期限、负责人和阶段进度。点击「打开任务」，或点击「推荐人选并查看」，进入任务签发弹窗。

任务弹窗集中显示背景、奖励、行动要求、负责人、成功率、方案、资源投入与失败代价。人员比较作为同一个弹窗的另一页；取消比较返回当前任务，选人也返回当前任务，不叠加遮罩。已签发任务只能查看或撤回，撤回立即释放预留资源。

地图、任职任务、地方委托和通知均进入同一任务弹窗。关闭或按 Esc 返回进入时所在的页面。授权不会推进夜晚；结束今夜前仍会显示组织安排确认。

## 人事档案

人事弹窗上方为成员名册，下方只显示当前成员的身份、机构、状态和四项能力。详细经历、生活牵挂、近期情况、身份经验和生活政策放入个人档案弹窗。

机构任职选择从档案进入；取消返回档案，创建任职任务后进入任务签发弹窗。任职任务的返回或 Esc 也回到同一成员档案；签发成功回到底层指挥页面。外观编辑从档案进入时，应用或放弃后返回同一份档案。

## 地图、联络网与地方事务

- 地图上的城区标记打开城区档案弹窗。地图标记保留当地待签发数及今夜截止风险；档案内列出当地任务。
- 联络网弹窗显示岗位、启停、待接与中继数量。具体岗位判定、最近记录在运行状况弹窗中查看。任务占岗、成员离岗、暂停和积压将失效仍直接提示。
- 地方事务弹窗保留当前追查和可发起委托；详细追查阈值、休整收益与委托规则集中在安全规则弹窗。

## 地图工作台与返回规则

新局、继续和读档都回到地图。业务窗口用同一遮罩阻止点穿到地图，详情替换当前窗口；返回时保留任务、成员、筛选与来源上下文。声音显示与指南均返回设置。浏览与关闭弹窗不推进夜晚、扣钱或授权任务。

## 自动检查

`--minglu-modal-smoke` 使用独立存档，点击任务打开、比较取消、筹备预览、授权和撤回、地图返回、个人政策与联络详情，并检查浏览没有推进时间、扣除资源或留下意外授权。另检查长任务正文滚动、任职任务返回档案，以及连续通知已阅后保留先前打开的任务。旧有 command、design、strategy、institution 界面烟测同步适配新入口。

`--map-desk-only` 专门检查地图常驻、五类业务窗口、真实射线遮挡、任务签发与撤回、成员选择保持，以及设置中的保存/读取/指南/音量/返回主菜单/继续。
