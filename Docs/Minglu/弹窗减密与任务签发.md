# 弹窗减密与任务签发

主界面保留本夜、可用资源、当前目标、任务期限、人员状态，以及「处理下一项」「结束今夜」。详情按玩家当前选择展开，避免把所有规则同时铺在屏幕上。

## 任务簿

任务卡只显示标题、地点、期限、负责人和阶段进度。点击「打开任务」，或点击「推荐人选并查看」，进入任务签发弹窗。

任务弹窗集中显示背景、奖励、行动要求、负责人、成功率、方案、资源投入与失败代价。人员比较作为同一个弹窗的另一页；取消比较返回当前任务，选人也返回当前任务，不叠加遮罩。已签发任务只能查看或撤回，撤回立即释放预留资源。

地图、任职任务、地方委托和通知均进入同一任务弹窗。关闭或按 Esc 返回进入时所在的页面。授权不会推进夜晚；结束今夜前仍会显示组织安排确认。

## 人事档案

常驻人事页只显示身份、机构、当前状态和四项能力。详细经历、生活牵挂、近期情况、身份经验和生活政策放入个人档案弹窗。

机构任职选择从档案进入；取消返回档案，创建任职任务后进入任务签发弹窗。任职任务的返回或 Esc 也回到同一成员档案；签发成功回到底层指挥页面。外观编辑从档案进入时，应用或放弃后返回同一份档案。

## 地图、联络网与地方事务

- 地图上的城区标记打开城区档案弹窗。地图和右侧概要继续保留当地待签发数及今夜截止风险；档案内列出当地任务。
- 联络网常驻显示岗位、启停、待接与中继数量。具体岗位判定、最近记录在运行状况弹窗中查看。任务占岗、成员离岗、暂停和积压将失效仍直接提示。
- 地方事务保留当前追查和可发起委托；详细追查阈值、休整收益与委托规则集中在安全规则弹窗。

## 自动检查

`--minglu-modal-smoke` 使用独立存档，点击任务打开、比较取消、筹备预览、授权和撤回、地图返回、个人政策与联络详情，并检查浏览没有推进时间、扣除资源或留下意外授权。另检查长任务正文滚动、任职任务返回档案，以及连续通知已阅后保留先前打开的任务。旧有 command、design、strategy、institution 界面烟测同步适配新入口。
