# 胡须、颈部与事件要报 v15.10

## 外观适配
保留用户确认的 v15.9 发型参数。胡须改以各素材实际嘴部开口中心配准，分别修正短须、长须、八字须锚点，并随脸型宽度适配。原来短须锚点偏高、长须锚点偏低，套用同一规则使胡须在唇部错位。

颈部根据男女八种脸型的原始颈宽、中心及嘴部高度确定位置；头像底部遮罩同步使用实际颈宽，避免不同脸型统一裁成同一宽度。衣服遮挡顺序和已确认发型不变。

## 事件表现
原有家事、大清查、信任危机的决策弹窗继续使用。新增：
- 同夜要报：新上级指示、内线/成员发现、身份升级、情报送达、任务完成及阶段推进，合并为一张可滚动弹窗；没有重要变化时不弹。
- 决定已执行：选择突发事件选项后，明确显示实际结果，并可跳转受影响的人事或链条。
- 要报的“前往”按钮定位对应任务或管理页；“已阅”留在当前页面。
- 待读要报保存在 command.notices 中；旧存档缺字段时初始化为空。确认即保存，读档不会重复展示已读消息。
- 结局与待决事件优先于普通要报，弹窗期间不会推进夜晚。
