# 头身与发型比例修正 v0.15.1

本次针对 v0.15 仍然头部偏大、发型体积与身体不协调的问题调整实际人物层级，不通过缩小整个预览框掩盖比例问题。

- 身体保持原始图像比例和400单位宽度；男性头部从280单位降到240，女性降到232，分别缩小约14.3%和17.1%。这是项目内的美术校准值，不是人体测量标准。
- 头部以颈根下缘298为固定点缩放，避免缩小后头部悬浮。衣领定位下移6单位，给颈部衔接留出空间。
- 头发、帽子、胡须的比例与锚点跟随实际头部尺寸，保留各自源图宽高比。前发渐隐边界同样改为相对头部坐标，避免发型缩小后仍使用旧遮挡位置。
- 编辑器、人物档案、随机成员、名录头像均使用同一几何数据；不改变五官选项、随机能力或已有存档结构。

新增同角色控制变量对照：上排固定脸与服装，只换四种发型；下排固定脸与发型，只换四套服装，旁边同时渲染名录尺寸。另保留8种脸/衣组合、全部男女发型和随机外观渲染。

构建：`Builds/MingluCity-v15.1/MingluCity.exe`。

验证证据：`Logs/portrait-v15.1-build.log`、`Logs/portrait-v15.1-ui.log`；对照图 `outputs/portrait-v15.1/check.proportion-s0.png` 与 `check.proportion-s1.png`。规则与外观实机验证通过，已人工查看男女同角色对照、扩展面容及衣领抽样、随机组合。组合抽样不等于穷举全部外观。

新手引导仍是独立设计稿，本版没有将其标记为已实现。
