# 组合外观 v0.9

参考《太阁立志传5》的部件组合方式，使用本项目原创矢量头像，未使用该游戏的人物图片或部件。官方参考：https://www.gamecity.ne.jp/regist_c/user/tr5/tr5_fan.htm ，https://www.gamecity.ne.jp/taikou5dx/features.html 。

## 使用方式

- 主菜单「负责人外观 / 组合头像」：设置下一局地区负责人的外观。
- 游戏内左上「负责人外观」：编辑本局负责人；头像显示在顶部状态栏。
- 选中队员 → 查看人物档案 → 自定义外观：编辑当前队员。应用后同步到名录、派遣面板与人物档案。
- 上方选择类别，下方选择部件，左侧立即预览。随机组合只影响外观，不消耗战役随机数。
- 「应用并保存」提交到当前对局；「取消」或关闭放弃预览。
- 「恢复原貌」后应用，可恢复队员原始立绘。负责人恢复默认组合头像。
- 预设按钮切换1—3号槽位，保存会覆盖所选槽；读取仅进入预览，仍需应用。预设跨局保留。

## 部件

13类：脸型、发式、眼睛、眉形、鼻形、嘴形、胡须、服装、饰物、背景、肤色、衣色、发色。每类4项，衣色6项，共54个选项。部件不按性别锁定。头像为半身组合图，不改变角色名字、身份、四能力、体力或风险。外观也不提供伪装加成。

当前画风为平涂矢量插画；既有角色可以继续使用原始绘制立绘。尚未实现照片导入、写实捏脸、全身动画换装、装备属性或外部美术包导入。

## 数据与扩展

`Appearance.parts`保存13类索引，`enabled`控制队员是否使用组合头像。`AppearanceRules`定义名称、范围校验、深拷贝和独立随机生成；`PortraitGraphic`按固定400×540坐标绘制分层部件，按显示框等比缩放，不为每个组合创建贴图文件。

角色外观与负责人外观随现有 `minglu-run-v8.json` 保存，本次不更换对局文件名。主菜单负责人默认外观及3个预设随 `minglu-profile-v1.json` 保存。旧档缺少外观字段时沿用原立绘，旧局负责人可以从游戏内入口编辑。

新增部件时同步扩充 `AppearanceRules.Names` 和 `PortraitGraphic` 对应分支；保持既有索引含义稳定。变更类别数量需同时实施存档迁移，不应直接删除旧类别。

入口脚本：`AppearanceUI.cs`；验证菜单：`Minglu > 验证组合外观`。运行界面测试参数：`--minglu-capture <输出PNG路径> --appearance-only`。测试使用隔离临时存档。
