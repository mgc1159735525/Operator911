# 写实比例与资源 v0.12

本版只保留写实编辑入口，移除经典切换按钮。旧经典预设在显示和编辑时转换成写实组合，原文件不会被批量覆盖；应用后保存当前写实选择。固定剧情成员原本的绘制立绘继续保留。

## 比例修正

先前头像在400×540参考画布上使用360像素头部，400像素宽的躯干又被强制压缩至258像素高，造成大头、窄肩和短躯干观感。

现在采用400×650参考画布：头部统一缩至260像素并居中；头发与胡须跟随同一缩放；躯干按图集原始宽高比绘制，不再单独压扁。领口与颈部重新对齐。名录、人物档案、负责人头像和编辑预览共用这套比例。

新程序位于 `Builds/MingluCity-v12/MingluCity.exe`。采用独立构建目录，以便保留用户正在运行的旧版窗口。继续使用现有存档和预设文件名。
