# 界面重设计：印刷档案

## 本轮解决的问题

旧界面的模板感主要来自：所有容器都使用相同切角、每个按钮都铺满灰色背景、导航与提交同等醒目、辅助说明重复、字号和字重缺乏节奏。此次改变布局和控件规则，不继续叠加装饰。

## 版式

- 顶部只放日期、三项主要资源和存读档入口。追查与民心保留在右上。
- 左侧为纵向文字目录：任务簿、联络网、人事档案、城区地图、值夜报告、地方事务。目录下展示当前目标与一项优先待办，减少与中央任务列表的重复。
- 中央使用暖纸色档案页。任务从独立黑色卡片改成连续编号条目，靠细线、缩进与字级区分信息；选中项仅增加窄侧标。
- 右侧为签发区域：角色照片、能力状态、任务简述、较大的成功率和唯一签发按钮。没有任务时保持简洁。
- 底部人员名册使用照片与紧凑文字；空位只显示一个招募入口。结束今夜固定在右下。
- 主菜单采用纵向文字目录，城市背景压暗，不再放宣传口号。新局设置使用对齐的登记栏目。

1600×900 参考布局：左栏 x32–260，正文 x286–1124，右栏 x1146–1568；正文起点 y122，人员名册 y748，结束操作 y855。中央继续保留838px宽度，任务、报告、人物页与复用弹窗不会因改框宽度产生内容裁切。

## 控件与美术规则

| 类别 | 表现 |
| --- | --- |
| 导航 | 透明文字行；当前页有窄侧标，不使用整排图标与大色块 |
| 筛选、方案、性别和部件分类 | 文字与底线，选中线变深；不冒充提交按钮 |
| 普通操作 | 平直矩形和一条轻底线，没有切角、高光边和渐变 |
| 查看、比较、返回等辅助操作 | 文字入口，必要时用方向符号提示可点击 |
| 签发、开始、应用 | 单一铁锈红实色，配暖白字；同一区域限制强调数量 |
| 缩略图与成员选择 | 只在选中项显示边界，人物图像颜色与比例不参与UI换色 |
| 弹窗 | 纸面、细分隔线、短色标、清晰遮罩；保留确认与取消的明确分工 |
| 悬停和按下 | 使用真实的 ColorTint 状态变化，键盘焦点保留独立轮廓 |
| 滚动条 | 淡轨、细把手，保留10px可点击区域 |

## 字体和配色

标题使用Windows宋体，正文使用微软雅黑；标题字体不可用时回退。标题不再全部加粗，正文仍以可读为先。

- 深底 `#1D2321`，正文 `#E7E3D7`，次级文字 `#ACB0A0`。
- 纸面 `#E6DFCF`，正文 `#282A27`，次级文字 `#5D6157`。
- 提交与风险强调 `#943F32`。状态同时使用文字说明，不只依赖颜色。
- 通过 `UISurfaceTheme` 明确区分纸面与暗面。人物贴图、皮肤与发色不做主题转换。

没有生成假纸纹、手写字或新角色贴图。新界面使用Unity原生平面图形、文字和现有角色/城市资产，减少素材之间的风格漂移。
