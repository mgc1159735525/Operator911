# 发型与颈肩重制 v15.3

## 原因与修改
旧发型的头骨体积、发际线、面孔开口不统一；旧头像下方只有短截脖颈，衣领按图片顶边拼接无法构成完整颈肩过渡。继续移动整张头部不能修复素材解剖结构。

本次通过内置 imagegen 重制男女共八种发型、男女颈肩素材。发型中去掉附带耳朵，用原生面容的耳朵；旧胡须仍独立使用原图集。统一发际线锚点和等比缩放，长发位于身体后侧，正面层在耳下淡出。新增颈部底层，原头像脖颈底部透明渐变，衣领闭合点下移，按领口限制颈肩素材的可见范围。

不改变保存的发型编号、五官选项或游戏规则。新贴图加载后旧存档直接使用新外观。
