# v0.3.1 交互优化

延续911 Operator的地图任务调度方向，以及This Is the Police的人物选择与行动反馈方向，具体实现为本项目回合制界面设计，不宣称复刻两款游戏的按键或实时流程。

## 已实现

- 地图显示可点击的限时任务标记，以文字区分「急」和「待」，选中任务和区域同步高亮。
- 任务卡「地图定位」直接切到对应区域，右侧显示同一任务的内容、期限和后果。
- 先选任务后选人：保持任务、区域及行为不变；左侧全部可行动成员同时显示该任务的成功率，方便比较。
- 点击已承接任务自动选中负责人；任务卡提供撤回负责人的入口，撤回立即释放AP和情报预留。
- 派遣前以规则层的同一校验逻辑在副本上检查，不改变真实状态。不足资源、重复负责人、被捕或无效营救目标等会显示原因并禁用签发。
- 按钮明确显示「派遣某人」「更新某人的指令」或「暂不可签发」，减少实际执行对象不清的问题。
- 重绘界面保留同名列表的滚动位置，切换成员与任务时无需重新寻找列表位置。

## 推荐操作

任务卡选任务 → 地图定位 → 左侧比较成员 → 右侧签发 → 任务卡查看负责人。需要改派时先在任务卡撤回，再选择新成员签发。地图区域按钮与普通行动按钮仍可退出任务选择，安排常规行动。

## 验证

新增UI射线测试覆盖：任务定位地图、地图切换任务、切换角色保留破坏任务、冲突派遣在点击前禁用、任务卡撤回释放AP，再重新派遣。原有营救、核实、存读档、密报和结局流程继续运行。

当前继续采用点击式回合调度。拖拽派遣、实时行进动画、声音报告和任务处理中的动态选择尚未实现。旧v3存档和现有配置表继续使用。
